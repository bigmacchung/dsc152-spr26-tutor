About this phase

Lab 6 is about INTERACTIONS. Very important for Quiz 2.

An interaction means: two things change something TOGETHER in a different way than they change it alone. We will use very simple English. Every level has 8 parts: simple idea → math words → connection → example → game → practice → answers → common mistakes.

Lab 6 uses a sleep study: people get a blue light filter (yes/no) AND a caffeine cutoff (yes/no). We want to know: does the filter only help when there is also a caffeine cutoff? That is the interaction question.

Level 60 — What is an Interaction? (Lab 6 Part 1 setup) +90 XP
🧠 Simple Explanation (very easy English)

Imagine you are baking. Sugar makes the cake sweet. Butter makes the cake soft.

But if you add MORE butter WHEN you also add MORE sugar, the cake gets EXTRA soft. The butter "helps more" when sugar is there too.

That extra effect — the part that only shows up when TWO things happen together — is an interaction.

In Lab 6: blue light filter alone helps sleep a little. Caffeine cutoff alone helps sleep a little. But do they together help EXTRA? That's the interaction question.

📐 Math Language (for exam)
  • Main effect: how much one thing (say, blue light) changes the outcome by itself.
  • Interaction effect: extra change that happens only when two things are present together.
  • Interaction model (2 binary predictors \(x_1, x_2\)): \[\hat y = \hat\beta_0 + \hat\beta_1 x_1 + \hat\beta_2 x_2 + \hat\beta_3 (x_1 \cdot x_2)\]
  • \(x_1 \cdot x_2\) is the interaction term (just the two columns multiplied).
  • R syntax: lm(y ~ x1 * x2) — the * means "include x1, x2, AND their interaction." Same as lm(y ~ x1 + x2 + x1:x2).
🔗 Connection (simple ↔ math)
Simple IdeaMath Language
"Blue light alone helps a little"Main effect \(\hat\beta_1\) (when caffeine_cutoff = no)
"Caffeine cutoff alone helps a little"Main effect \(\hat\beta_2\) (when blue_light = no)
"Extra help when BOTH happen"Interaction \(\hat\beta_3\)
"Baseline when NEITHER happens"Intercept \(\hat\beta_0\)
"Filter only works WHEN you also cut caffeine"\(\hat\beta_3 \neq 0\) (interaction exists)
"Filter works the same no matter caffeine"\(\hat\beta_3 \approx 0\) (no interaction)
🍎 Intuitive Example — Lab 6 sleep study (small numbers)

Imagine 4 groups of people:

  • Group A: NO filter, NO caffeine cutoff. Mean sleep score = 5.
  • Group B: NO filter, YES caffeine cutoff. Mean sleep score = 6 (cutoff helps +1).
  • Group C: YES filter, NO caffeine cutoff. Mean sleep score = 6 (filter helps +1).
  • Group D: YES filter, YES caffeine cutoff. Mean sleep score = 9 (not 7 — way better!).

If there was NO interaction, Group D should be about 5 + 1 + 1 = 7. But it's 9. The "extra 2" is the interaction effect.

Math: \(\hat\beta_0 = 5\), \(\hat\beta_1 = 1\), \(\hat\beta_2 = 1\), \(\hat\beta_3 = 2\). The filter is much more powerful when caffeine is also cut.

✅ Answers + Explanations
  1. (b) Extra effect when both happen.
  2. It includes BOTH main effects (x1, x2) AND their interaction (x1:x2).
  3. True. β₃ = 0 means treatments are additive.
  4. "Blue light is 1.5 units LESS helpful when caffeine cutoff is also done. They cancel a bit." (Or equivalently: caffeine cutoff is 1.5 less helpful when blue light is done.)
  5. β̂₃ = (yes/yes − no/yes) − (yes/no − no/no) = (9 − 6) − (6 − 5) = 3 − 1 = 2.
  6. summary(lm(y ~ A * B, data=df))$coefficients["A:B","Pr(>|t|)"] (column index may vary by exact level names)
  7. Less typing, same model. Same coefficients, same p-values.
  8. R uses "no" as the reference (alphabetical), so the "active" level appears in row names. "yes:yes" = the interaction term column where both indicators = 1.
  9. "An interaction is when the effect of one variable DEPENDS ON the level of another variable."
  10. lm(y ~ x1 * x2) and lm(y ~ x1 + x2 + x1:x2) — identical.
  11. \(y_i = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \beta_3 (x_{1i} \cdot x_{2i}) + \epsilon_i\)
  12. "The boost from the blue light filter is 2.5 sleep points BIGGER when the caffeine cutoff is also done, compared to when it is not done. (p = 0.002 → highly significant.)"
  13. Separate tests cannot detect an interaction. Each only sees one factor at a time. The interaction needs both variables and their product in ONE model.
⚠️ Common Mistakes
  1. "Main effect" ≠ "average effect over both groups." The main effect coefficient \(\hat\beta_1\) is the effect of \(x_1\) when \(x_2 = 0\), not averaged. The interaction \(\hat\beta_3\) tells you how much extra to add when \(x_2 = 1\).
  2. Reading the main-effect p-value as "this variable matters." With interactions, this is misleading. See Level 63.
  3. Forgetting the * creates 3 things, not 1. Always count: 4 coefficients for 2 binary predictors with interaction (intercept + 2 mains + 1 interaction).
Level 61 — Reading Interaction Plots (parallel or not?) +85 XP
🧠 Simple Explanation

You plot two lines on a chart. One line shows what happens with treatment A. The other line shows what happens without treatment A.

Two lines parallel = lines stay at the same distance everywhere = treatments work independently = NO interaction.

Lines NOT parallel (they spread or cross) = the gap changes = INTERACTION exists.

📐 Math Language
  • Interaction plot: x-axis = one categorical predictor; y-axis = mean outcome; one line per level of the OTHER predictor.
  • Geometric meaning: parallel ↔ \(\hat\beta_3 \approx 0\). Not parallel ↔ \(\hat\beta_3 \neq 0\).
  • Slope difference = \(\hat\beta_3\) when both predictors are binary (0/1). The bigger the slope difference, the stronger the interaction.
  • Difference-in-differences: \(\delta_{cf} = (\bar y_\text{yes,yes} - \bar y_\text{no,yes}) - (\bar y_\text{yes,no} - \bar y_\text{no,no})\). Informal measure of interaction. Equals \(\hat\beta_3\) in a saturated 2×2 model.
🔗 Connection
Plot you seeWhat it means
Two parallel linesNo interaction → \(\hat\beta_3 \approx 0\)
Lines spread further apart on rightPositive interaction → \(\hat\beta_3 > 0\)
Lines come closer together on rightNegative interaction → \(\hat\beta_3 < 0\)
Lines CROSS (X shape)Strong interaction; effect reverses
🍎 Intuitive Example — Lab 6 sleep plot

x-axis: blue_light (no, yes). Two lines: one for caffeine_cutoff=no, one for caffeine_cutoff=yes.

If the line "with caffeine cutoff" goes UP much more from no → yes than the "without" line, the lines are NOT parallel → interaction.

If both lines rise by the same amount, parallel → no interaction.

For our 5/6/6/9 example: "no cutoff" line: 5 → 6 (rise of 1). "yes cutoff" line: 6 → 9 (rise of 3). Different slopes → interaction.

✅ Answers
  1. (b) No interaction.
  2. One categorical predictor (e.g., blue_light: no/yes).
  3. True. Crossing = effect direction reverses = strong interaction.
  4. \(\delta = (18 − 10) − (14 − 10) = 8 − 4 = 4\)
  5. The predictor on the x-axis has NO effect (slopes are zero); but if the OTHER predictor's line is at a different level, that one has an effect.
  6. Strong interaction (opposite slopes). Lines cross.
  7. No-interaction model: lines are ALWAYS parallel (same slope). With-interaction model: lines can have different slopes.
  8. Nearly parallel lines, very small gap difference. Visual interaction is small or absent.
  9. The slopes of the two lines differ; the effect of the x-axis variable depends on which group (line) you are looking at.
  10. \(\delta = (\bar y_\text{1,1} − \bar y_\text{0,1}) − (\bar y_\text{1,0} − \bar y_\text{0,0})\)
  11. Group means in a 2×2 design are: \(\bar y_\text{0,0} = \beta_0\); \(\bar y_\text{1,0} = \beta_0 + \beta_1\); \(\bar y_\text{0,1} = \beta_0 + \beta_2\); \(\bar y_\text{1,1} = \beta_0 + \beta_1 + \beta_2 + \beta_3\). Plug into δ formula → all βs cancel except \(\beta_3\).
  12. It computes the mean of y for every combination of x1 and x2 — exactly the 4 group means you need for an interaction plot.

⚠️ Common Mistakes
  1. Confusing parallel lines with a flat line. Parallel just means same slope — could be both flat OR both going up at the same angle.
  2. Eyeballing a "big" visual gap as significant. Always check the p-value for \(\hat\beta_3\). Small samples can have wide CIs.
  3. Reading interaction plot but using only main effects in model. If you SEE non-parallel lines, you NEED an interaction term in the model.
Level 62 — Interpreting Each β in an Interaction Model +90 XP
🧠 Simple Explanation

The interaction model has 4 numbers (β₀, β₁, β₂, β₃). Each tells you a different story.

  • β₀ = baseline (when nothing is on)
  • β₁ = effect of treatment 1, BUT ONLY WHEN treatment 2 is off
  • β₂ = effect of treatment 2, BUT ONLY WHEN treatment 1 is off
  • β₃ = EXTRA effect when both are on together

The "only when" part is the most important. Many students forget this.

📐 Math Language (Lab 6 Q1.5 exact)

Model: \(\hat y = \hat\beta_0 + \hat\beta_1 x_1 + \hat\beta_2 x_2 + \hat\beta_3 x_1 x_2\)

  • \(\hat\beta_0\): predicted y when \(x_1 = 0\) AND \(x_2 = 0\) (both treatments OFF).
  • \(\hat\beta_1\): change in predicted y when \(x_1 = 1\) but \(x_2 = 0\). NOT "the average effect of x1."
  • \(\hat\beta_2\): change in predicted y when \(x_2 = 1\) but \(x_1 = 0\).
  • \(\hat\beta_3\): EXTRA change in predicted y when BOTH \(x_1 = 1\) AND \(x_2 = 1\), beyond \(\hat\beta_1 + \hat\beta_2\).
  • Effect of \(x_1\) when \(x_2 = 1\): \(\hat\beta_1 + \hat\beta_3\).
🔗 Connection — Plug-In Table
Group\(x_1\)\(x_2\)Predicted \(\hat y\)
Nothing on (baseline)00\(\hat\beta_0\)
Only Treatment 110\(\hat\beta_0 + \hat\beta_1\)
Only Treatment 201\(\hat\beta_0 + \hat\beta_2\)
Both treatments11\(\hat\beta_0 + \hat\beta_1 + \hat\beta_2 + \hat\beta_3\)
🍎 Intuitive Example — Lab 6 numeric (Q1.6)

Suppose R fits: \(\hat\beta_0 = 4.5\), \(\hat\beta_1 = 0.8\) (blue_light), \(\hat\beta_2 = 1.1\) (caffeine_cutoff), \(\hat\beta_3 = 1.4\) (interaction).

  • Predicted sleep with nothing: 4.5
  • Predicted sleep with ONLY blue light: 4.5 + 0.8 = 5.3
  • Predicted sleep with ONLY caffeine cutoff: 4.5 + 1.1 = 5.6
  • Predicted sleep with BOTH: 4.5 + 0.8 + 1.1 + 1.4 = 7.8

Effect of blue light WHEN caffeine cutoff is on: \(\hat\beta_1 + \hat\beta_3 = 0.8 + 1.4 = 2.2\). Much bigger than the "alone" effect of 0.8.

⚠️ Common Mistakes
  1. Forgetting "when x₂ = reference." The main effects in an interaction model are conditional.
  2. Confusing \(\hat\beta_3\) with \(\delta\). They are equal in a saturated 2×2, but \(\delta\) is the descriptive difference-in-differences; \(\hat\beta_3\) is the model coefficient with a SE and p-value.
  3. Computing the "yes/yes" mean by adding only β₀ + β₁ + β₂. Forgetting β₃ undercounts (or overcounts) by exactly the interaction.
Level 63 — When the Individual t-test Lies: Partial F vs t (Lab 6 Part 2) +95 XP
🧠 Simple Explanation

R's summary(model) gives you a row for each coefficient with a p-value. Easy to read those p-values one by one. But...

If a variable appears in BOTH a main effect AND an interaction, looking at only ONE row LIES to you about whether that variable matters.

Example: if blue light helps only WHEN caffeine cutoff is done, the individual t-test for \(\hat\beta_1\) might say "p = 0.40, not significant." But blue light DOES matter — just not by itself. The right test combines β₁ AND β₃ together.

That combined test is the partial F-test. It asks: "is this variable USEFUL anywhere in the model?"

📐 Math Language
  • Individual t-test for β₁: tests \(H_0: \beta_1 = 0\) while holding the rest of the model FIXED. Only tests the main effect at reference level of x₂.
  • Partial F-test for "does x₁ contribute at all?": tests \(H_0: \beta_1 = 0 \text{ AND } \beta_3 = 0\) jointly. Drops BOTH the main and interaction terms.
  • Partial F formula: \(F = \dfrac{(RSS_\text{reduced} - RSS_\text{full})/p}{RSS_\text{full}/(n-k)}\) where \(p\) = number of dropped coefficients (here 2).
  • R: anova(reduced_model, full_model) — same as Lec 9.
  • R for interaction only: drop only β₃ → compare lm(y ~ x1 + x2) vs lm(y ~ x1 * x2).
🔗 Connection — Two Different Tests
QuestionWhat you testHow
"Does x₁ matter, holding everything else fixed?"\(H_0: \beta_1 = 0\) (one coefficient)Individual t in summary()
"Does x₁ matter ANYWHERE in the model?"\(H_0: \beta_1 = \beta_3 = 0\) (joint)Partial F via anova(red, full)
"Is there an interaction?"\(H_0: \beta_3 = 0\)Partial F dropping only β₃
"Does ANY predictor matter?"\(H_0: \beta_1 = \beta_2 = \beta_3 = 0\)Overall F (at bottom of summary())
🍎 Intuitive Example — Lab 6 Scenario B (Q2.3.2)

Scenario B: blue light only helps when caffeine cutoff is on. \(\beta_1 = 0, \beta_3 = 3\).

  • Individual t-test for \(\hat\beta_1\): p = 0.40 → "fails to reject." Looks like blue light doesn't matter.
  • BUT: \(\hat\beta_3\) is large with p = 0.001. The interaction is significant.
  • Partial F for both (\(H_0: \beta_1 = \beta_3 = 0\)): p < 0.001. STRONGLY reject. Blue light DOES matter — through its interaction with caffeine cutoff.

Lesson: don't trust a single t-test row when interactions are in the model.

🎮 Interactive — All 3 tests in R
full     <- lm(sleep_score ~ blue_light * caffeine_cutoff, data=sleep_df)

# Test 1: individual t for β̂₁
summary(full)$coefficients["blue_lightyes", "Pr(>|t|)"]

# Test 2: partial F — "does blue_light contribute AT ALL?"
no_blue <- lm(sleep_score ~ caffeine_cutoff, data=sleep_df)
anova(no_blue, full)
# p-value here tests H₀: β₁ = β₃ = 0

# Test 3: partial F — "is there an INTERACTION?"
no_interaction <- lm(sleep_score ~ blue_light + caffeine_cutoff, data=sleep_df)
anova(no_interaction, full)
# p-value here tests H₀: β₃ = 0 only
# NOTE: this p-value should match the individual t for β₃ in summary().

⚠️ Common Mistakes
  1. "Variable not significant in summary() → drop it from model." Wrong if the variable also appears in an interaction. Use partial F first.
  2. Confusing overall F (bottom of summary) with partial F. Overall F tests EVERY predictor jointly vs intercept-only. Partial F isolates a subset.
  3. Forgetting the right test name. "I ran anova" doesn't specify the comparison. Always say "partial F comparing X to Y."

🎮 Lab 6 Power Simulation (Q2.7-2.9)
# Simulate power of partial F-test vs individual t-test under 3 scenarios:
# Scenario 1: β₁ = 2, β₃ = 0  (only main effect)
# Scenario 2: β₁ = 1, β₃ = 1  (both effects)
# Scenario 3: β₁ = 0, β₃ = 3  (only interaction)

sim_ftest_power <- function(beta1, beta3, n, n_sim=1000) {
  rejections <- replicate(n_sim, {
    x1 <- rbinom(n, 1, 0.5)
    x2 <- rbinom(n, 1, 0.5)
    y  <- beta1*x1 + 0.5*x2 + beta3*x1*x2 + rnorm(n)
    full <- lm(y ~ x1 * x2)
    red  <- lm(y ~ x2)
    anova(red, full)$`Pr(>F)`[2] < 0.05
  })
  mean(rejections)
}

# interaction-only effect in Scenario 3 entirely.
