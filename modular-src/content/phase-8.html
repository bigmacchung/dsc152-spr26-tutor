Two Different Goals, Two Different Hygiene Standards
SettingGoalDiagnostic step?
Statistical inference (this class)Make a calibrated probabilistic claim about the population (p-value, CI)YES — required. p-values and CIs are only valid if conditions hold.
Machine learningMinimize prediction error on held-out dataMostly NO. Cross-validation already measures what you care about.
Analogy — The Speedometer vs the Stopwatch

ML is a stopwatch: "did I get there fast?" You time the run; if it's good, you're done — you don't need to inspect the engine. Stats inference is a speedometer + odometer + map: you're claiming "I will arrive at 60 ± 5 mph." That claim is only meaningful if the instruments are calibrated. Diagnostics are calibration checks.

⚠️ Failing Diagnostics ≠ Failing the Class

"Failure" of a LINE check doesn't mean throw the model out. It means: (1) you can't trust the p-values/CIs as-is, and (2) you should report what you tried — transformations, robust SE, switching to non-parametric. The point is honesty about what your test is licensed to claim.

Level 40 — Residuals: the diagnostic tool +45 XP
Definition

For each data point \(i\):

$$\epsilon_i = y_i - \hat y_i$$

where \(\hat y_i = \hat\beta_0 + \hat\beta_1 x_i\) (or with more terms for MLR). Residuals are the observed minus predicted values. They're the empirical proxy for the error term in the LINE model.

Why Residuals?

The LINE conditions are written about the unobservable noise \(\epsilon_i \sim N(0, \sigma^2)\). We can't see ε directly, but the residuals are our best estimate of it. So we plot/test the residuals to check what we hope is true about ε.

R Code — extract residuals + fitted values
model1 <- lm(bracket_score ~ knowledge, data=march_madness)

names(model1)
# [1] "coefficients"  "residuals"     "effects"
# [4] "rank"          "fitted.values" "assign" ...

res <- model1$residuals
fit <- model1$fitted.values

# Cross-check (first 3 points):
head(march_madness$bracket_score - fit, 3)
head(res, 3)   # identical
Analogy — The Echo

If you fit the right line, the residuals should look like white noise — random, centered at 0, evenly spread, no patterns. Any pattern in the residuals is an "echo" of something the model failed to capture: a curve, an outlier, a trend over time, a heteroskedastic fan.

Quiz
A residual is positive. What does that tell you?
The actual y is above the fitted line for that point — the model under-predicted.
The actual y is below the fitted line — the model over-predicted.
The slope is positive.
The data is non-normal.

R Code — full LINE check on a fitted model
model <- lm(y ~ x, data=df)
res <- model$residuals
fit <- model$fitted.values

# L & E: residuals vs fitted
plot(res ~ fit,
     xlab="Fitted values", ylab="Residuals")
abline(h=0, lty=2, col="red")

# N: histogram + QQ plot
hist(res, breaks=20)
qqnorm(res); qqline(res, col="red")
shapiro.test(res)        # formal normality test

# I: residuals vs index (assumes data sorted by collection order)
plot(res ~ seq_along(res),
     xlab="Order", ylab="Residuals")
abline(h=0, lty=2)
⚠️ I (Independence) Cannot Be Diagnosed From Data Alone

You cannot tell if observations are independent just by looking at residuals. You need to know how the data was collected: were measurements taken on the same subject over time? Were students in the same classroom (cluster)? Were trials adjacent in time (autocorrelation)? The "residuals vs order" plot only catches independence violations that produce visible time-ordered patterns. Cluster/grouped non-independence is invisible to that plot.

Quiz
A QQ plot of residuals shows the points curving up at both ends ("fat tails" — way above the diagonal in the upper-right, way below in the lower-left). Which LINE letter is broken, and what's the practical impact?
L broken; fix by transforming x.
N broken (non-normal residuals with fat tails). For small n, p-values from t-tests and CIs may be off; for large n, CLT helps. Consider bootstrap or a robust alternative.
E broken; use weighted least squares.
I broken; use time-series methods.
Level 42 — Q-Q Plots & Shapiro-Wilk (reading normality) +45 XP
What a Q-Q Plot Actually Plots

For each residual, plot:

  • x-axis: the quantile that residual would have under a perfect normal distribution
  • y-axis: the empirical quantile (the residual's actual rank-based position)

If your residuals were perfectly normal, the points would lie exactly on a straight line. Departures from the diagonal map to specific distributional sins.

Reading the Curves
Q-Q shapeDiagnosis
Points hug the diagonalNormal residuals ✓
S-shape (curves both ways)Heavy tails (more extreme values than normal)
Reverse-S (sags both ways)Light tails (fewer extreme values than normal)
Curves up on right + flat on leftRight-skewed residuals
Curves down on left + flat on rightLeft-skewed residuals
R Code — make and read
model <- lm(y ~ x, data=df)
qqnorm(model$residuals)
qqline(model$residuals, col="red")

# Formal test: H0 = residuals are normal
shapiro.test(model$residuals)
#   Shapiro-Wilk normality test
#   W = 0.991, p-value = 0.34
# Big p (no evidence against H0): "looks normal enough"
⚠️ Shapiro-Wilk Has the Opposite Problem of Most Tests

With LARGE n, Shapiro-Wilk will reject normality for tiny, practically irrelevant deviations (Lec 5's Big Data Trap, again!). With SMALL n, it has poor power and rarely rejects. The honest practice: use the QQ plot as your primary tool, treat the formal test as a secondary check. Visual inspection scales better than the test in both directions.

Analogy — Lining Up at a Carnival

Imagine your residuals lining up by height. The QQ plot asks: "if your residuals had the heights they'd have under a normal distribution, would the line of people look the same?" Each person's actual height plotted against their predicted-normal height. If everyone's where the normal would put them, you get a straight diagonal. If a few people in the back row are unusually tall, the upper-right curls upward.

Level 43 — Quiz 2 Practice: full workflow on a fresh dataset +80 XP
Scenario

You're given a dataset of n=120 employees. Outcome: productivity (score 0–100). Predictors: training_hours (continuous), department (3 levels: Eng, Sales, Ops), tenure_years (continuous). Your manager asks: "Does training help productivity, after we account for department and tenure?"

Step-by-Step Plan
  1. Frame: H₀: β_training_hours = 0 in the model with all three predictors. H_A: ≠ 0.
  2. Visualize: scatterplot of productivity vs training_hours, colored by department. Boxplot of productivity by department.
  3. Fit the full model: lm(productivity ~ training_hours + department + tenure_years, data=df).
  4. Read off the t-test for training_hours from summary()$coefficients[2,4].
  5. If you wanted "is department relevant overall?": partial F via anova(lm(productivity ~ training_hours + tenure_years), full_model).
  6. Diagnostics: residuals vs fitted (L+E), QQ plot (N), residuals vs order (I).
  7. Conclusion: report estimate + 95% CI + p-value + diagnostic verdict, in plain English.

H₀: \(\beta_{\text{training\_hours}} = 0\) in the model that adjusts for department and tenure_years.
H_A: \(\beta_{\text{training\_hours}} \neq 0\).

Why this null and not the simpler one? Because the manager's question is after accounting for department and tenure. We need both confounders in the model.

full <- lm(productivity ~ training_hours + department + tenure_years, data=df)
library(knitr)
kable(summary(full)$coefficients)
confint(full, "training_hours")

# Optional: omnibus test that department matters at all
no_dept <- lm(productivity ~ training_hours + tenure_years, data=df)
anova(no_dept, full)

# Diagnostics
res <- full$residuals; fit <- full$fitted.values
par(mfrow=c(1,3))
plot(res ~ fit, main="L & E"); abline(h=0)
qqnorm(res, main="N"); qqline(res)
plot(res ~ seq_along(res), main="I"); abline(h=0)

"After adjusting for department and tenure, training_hours was [significantly / not significantly] associated with productivity (β̂ = X.XX, 95% CI: [a.aa, b.bb], p = 0.0XX). Specifically, comparing employees in the same department with the same tenure, each additional hour of training is associated with an estimated X.XX-point change in productivity. Diagnostic plots showed [no concerning patterns / a slight fan in residuals vs fitted suggesting mild heteroskedasticity / etc.] These results are observational; we cannot infer that training causes productivity gains."
