R Function Glossary — Binomial (needed for the sign test)
# dbinom(k, size = n, prob = p)
#   Probability of EXACTLY k successes in n trials with success prob p.
#   "Height of the bar at k" in a Binomial(n, p) histogram.
dbinom(2, size = 7, prob = 0.5)
# = P(X = 2) with 7 flips of a fair coin ≈ 0.164

# pbinom(k, size = n, prob = p)
#   Probability of AT MOST k successes (left-tail CDF).
pbinom(2, size = 7, prob = 0.5)
# = P(X ≤ 2) ≈ 0.227

# Sign test two-sided p-value pattern (from Practice Quiz 1 Q4 & Q5):
pbinom(min_count, size = n, prob = 0.5) * 2

# rbinom(n_draws, size, prob)
#   Simulate random Binomial counts.
rbinom(5, size = 10, prob = 0.5)
# = 5 random values of "# heads in 10 flips", e.g. 6 4 5 7 3
Remember the prefixes: d = density (exact value), p = probability (cumulative ≤), r = random (simulate).
For the sign test, n is the number of non-zero differences and p = 0.5 under H0.
R Function Glossary — t-Distribution (useful for manual t-test math)
# pt(t_stat, df)
#   CDF of the t-distribution: P(T ≤ t_stat) with df degrees of freedom.
pt(2.0, df = 9)
# = P(T ≤ 2.0) ≈ 0.963

# Two-sided p-value for observed t-stat with df = n - 1:
2 * (1 - pt(abs(t_stat), df = n - 1))

# qt(p, df)
#   Quantile function: the t-value with left-tail area = p.
qt(0.975, df = 9)
# ≈ 2.262  (critical value for a 95% two-sided CI with n = 10)
qt(0.975, df = n-1) is the "t* critical value" that appears in a manual t-CI: x̄ ± t* · s/√n.
pt turns a t-statistic into a p-value. qt turns a probability into a t-value. They are inverses.
R Function Glossary — Gamma (the "skewed data" distribution)
# dgamma(x, shape, scale)
#   Height of the gamma density at x.
dgamma(10, shape = 2, scale = 5)
# ≈ 0.054  (density at x = 10 for Gamma(2, 5))

# rgamma(n, shape, scale)
#   Generate n random draws from Gamma(shape, scale).
#   Mean = shape * scale. Right-skewed.
set.seed(1)
rgamma(5, shape = 1.2, scale = 20/1.2)
# = skewed sample with true mean = 20 (from Practice Quiz 1 Q3b)
Shape controls skewness: small shape (e.g., 1.2) = heavily right-skewed.
To make the mean equal any value M, set scale = M / shape.
You mostly use rgamma in Quiz 1 to simulate SKEWED data for Type I Error experiments.

Top 10 Traps to Avoid
  1. rnorm 3rd arg is SD, not variance
  2. 1:10 includes both endpoints (unlike Python)
  3. R indexing starts at 1, not 0
  4. Negative indexing REMOVES (not wrap-around like Python)
  5. "Fail to reject" not "accept H0"
  6. p-value is NOT P(H0 true)
  7. Small p + large n does not mean effect matters
  8. set.seed() must come BEFORE random functions
  9. Sign test tests MEDIAN, not mean
  10. : only does integer steps (use seq() for decimals)

Appendix — Bootstrap vs Permutation Test (Quick Compare) +20 XP
Why This Appendix Exists

Bootstrap and permutation tests sound similar — both use resampling — but they answer different questions. Permutation is NOT a Quiz 1 topic, so this is a short reference to keep the two methods from blurring together.

The One-Sentence Difference
  • Bootstrap: resample WITH replacement from your data to estimate how much a statistic (like the mean) bounces around. Answers "what's my confidence interval?"
  • Permutation test: shuffle the group labels between two groups to build a null distribution. Answers "could this difference between Group A and Group B have happened by chance?"
Side-by-Side Table
AspectBootstrapPermutation Test
PurposeConfidence interval / uncertainty of a statisticHypothesis test for "no difference between groups"
What you resampleValues from one sample, WITH replacementGroup LABELS, WITHOUT replacement (reshuffled)
Typical setupOne sample, asking about its mean / median / SDTwo samples, asking if they differ
Decision ruleReject H0 if mu0 is OUTSIDE the CIp-value = fraction of shuffles producing an at-least-as-extreme difference
On Quiz 1?Yes (Lecture 5, Practice Q8)No — just know it exists
Micro-Example (for orientation only)
# Bootstrap — CI for mean of one sample
boot_means <- replicate(10000,
  mean(sample(x, replace = TRUE)))
quantile(boot_means, c(.025, .975))

# Permutation — p-value for two-sample mean difference
obs  <- mean(a) - mean(b)
pool <- c(a, b)
diffs <- replicate(10000, {
  shuffled <- sample(pool)
  mean(shuffled[1:length(a)]) - mean(shuffled[(length(a)+1):length(pool)])
})
mean(abs(diffs) >= abs(obs))   # = permutation p-value
Bootstrap: sample WITH replacement from a SINGLE sample, many times. Look at quantiles.
Permutation: merge the two groups, shuffle labels (WITHOUT replacement), recompute the difference. Count how often it's at least as big.
Memory aid: Bootstrap = replacement. Permutation = shuffle.
Quiz 1 Reality Check

If a Quiz 1 question describes resampling a single sample with replacement and building a CI, it's the bootstrap. If a question describes reshuffling labels between two groups, it's a permutation test — mention it, but know you won't be asked to code it.

Q14 — Short Code Prompt: Power Simulation for Sign Test

Estimate the power of a two-sided sign test at α = 0.05 with n = 20, when data ~ N(mean = 0.8, sd = 2) and H0: median = 0. Use 10,000 reps.

Click for solution 
sign_test_pval <- function(x, mu0 = 0) {
  x <- x[x != mu0]
  n <- length(x)
  a <- sum(x > mu0)
  pl <- pbinom(a,     size = n, prob = 0.5)
  ph <- pbinom(a - 1, size = n, prob = 0.5, lower.tail = FALSE)
  min(1, 2 * min(pl, ph))
}

set.seed(1)
B <- 10000; n <- 20
reject <- logical(B)
for (b in 1:B) {
  samp <- rnorm(n, mean = 0.8, sd = 2)
  reject[b] <- sign_test_pval(samp, mu0 = 0) < 0.05
}
mean(reject)
Q15 — Short Code Prompt: Find Best Cutoff, Report Actual α

For H0: p = 0.40 vs. Ha: p > 0.40 with n = 18, find the one-sided rejection region closest to α = 0.05. Print the rejection region boundary and the actual α.

Click for solution 
n <- 18; p0 <- 0.40
cutoffs <- 0:n
alphas <- sapply(cutoffs, function(k) {
  pbinom(k - 1, size = n, prob = p0, lower.tail = FALSE)
})
idx <- which.min(abs(alphas - 0.05))
cat("Rejection region: {", cutoffs[idx], ", ..., ", n, "}\n")
cat("Actual alpha:", round(alphas[idx], 4), "\n")
