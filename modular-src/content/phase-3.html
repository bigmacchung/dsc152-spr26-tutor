Q3.3: calc_ts Function (t-statistic)

Lab 1 Q3.3
calc_ts <- function(data, mu0) {
  x_bar <- mean(data)
  s <- sd(data)
  n <- length(data)
  t_stat <- (x_bar - mu0) / (s / sqrt(n))
  return(t_stat)
}
This manually calculates the t-statistic: (sample mean - claimed mean) / standard error.

Q1.1: Why t-test Has Inflated Type I Error on Gamma

Key Idea

The t-test assumes normality. Gamma is right-skewed. With small n, CLT has not kicked in, so the t-test rejects MORE than it should (e.g., 0.07 instead of 0.05).

Q1.4: Bootstrap Type I Error -- Double Loop

Lab 2 Q1.4
set.seed(42)
n <- 30
n_sims <- 1000       # Outer: how many datasets
B <- 1000            # Inner: bootstrap resamples per dataset
mu0 <- 6
rejections <- 0

for (i in 1:n_sims) {
  data <- rgamma(n, shape = 2, scale = 3)

  # Bootstrap CI for this dataset
  boot_means <- rep(0, B)
  for (j in 1:B) {
    boot_sample <- sample(data, n, replace = TRUE)
    boot_means[j] <- mean(boot_sample)
  }
  ci <- quantile(boot_means, c(0.025, 0.975))

  # If mu0 outside CI, reject
  if (mu0 < ci[1] || mu0 > ci[2]) {
    rejections <- rejections + 1
  }
}
type1_boot <- rejections / n_sims
Double loop: OUTER creates different datasets. INNER does bootstrap within each.
|| is the OR operator in R (like or in Python).

Q2.2: sim_power_t Function

Lab 2 Q2.2
sim_power_t <- function(n, mu0, delta, sd, n_sims = 10000, alpha = 0.05) {
  rejections <- 0
  true_mean <- mu0 + delta

  for (i in 1:n_sims) {
    data <- rnorm(n, mean = true_mean, sd = sd)
    p <- t.test(data, mu = mu0)$p.value
    if (p < alpha) {
      rejections <- rejections + 1
    }
  }
  return(rejections / n_sims)
}

Q1.2: Large vs Small Sample t-test

# Large sample: tiny effect becomes significant
set.seed(42)
large_data <- rnorm(100000, mean = 50.01, sd = 10)
t.test(large_data, mu = 50)$p.value   # Very small!
t.test(large_data, mu = 50)$conf.int  # Very narrow CI

# Small sample: same tiny effect NOT significant
small_data <- rnorm(20, mean = 50.01, sd = 10)
t.test(small_data, mu = 50)$p.value   # Large p-value

Q1.3: Interpretation (Answer: 2)

Key Idea

Even though p is tiny, the actual difference is negligible. The correct interpretation: "Statistically significant but NOT practically meaningful."

Q1.4.2: Why p-values Differ (Answer: 3)

Key Idea

Sample size changes the standard error (SE = s/sqrt(n)). With n = 100,000, SE is tiny, so even 0.01 difference looks "many SEs away." With n = 20, SE is large, same difference is within noise.
