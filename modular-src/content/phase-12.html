Level 56 — Simple Linear Regression + Inference for the Slope +90 XP
🧠 Simple Explanation

You have two number columns: an x (predictor) and a y (outcome). You want to draw a line through the cloud of points.

The line has a starting height (intercept) and a tilt (slope). The slope says: "for every +1 in x, y goes up by this much."

The big question: "Is the slope really not zero, or does it just look that way by accident?"

📐 Math Language
  • Model: \(y_i = \beta_0 + \beta_1 x_i + \epsilon_i\), \(\epsilon_i \sim N(0, \sigma^2)\)
  • Estimated line: \(\hat y = \hat\beta_0 + \hat\beta_1 x\)
  • Least squares: \(\hat\beta_1 = \dfrac{\sum (x_i - \bar x)(y_i - \bar y)}{\sum (x_i - \bar x)^2}\), \(\hat\beta_0 = \bar y - \hat\beta_1 \bar x\)
  • Test for slope: \(H_0: \beta_1 = 0\), test stat \(t_s = \hat\beta_1 / SE(\hat\beta_1)\), df = \(n - 2\)
  • R: summary(lm(y ~ x))$coefficients[2, 4] = slope p-value
🔗 Connection
SimpleMath
"Best-fit line"Least-squares regression line
"Tilt of the line"Slope \(\hat\beta_1\) (sample) → \(\beta_1\) (true population)
"Where line crosses y-axis"Intercept \(\hat\beta_0\)
"True relationship vs estimated"\(\beta_1\) (no hat) vs \(\hat\beta_1\) (hat)
"Gap between point and line"Residual \(\epsilon_i = y_i - \hat y_i\)
"Is the tilt real?"Test \(H_0: \beta_1 = 0\)
🍎 Intuitive Example — March Madness

n = 50 students. x = basketball knowledge (0–10), y = bracket score.

  • R fits: \(\hat y = -100 + 38.4 \cdot x\). For each +1 knowledge → +38.4 bracket points (in this sample).
  • R reports p < 0.001 for \(\hat\beta_1\). Reject \(H_0: \beta_1 = 0\).
  • Conclusion: "There is statistically significant evidence at α=0.05 that knowledge is associated with bracket score."

Level 57 — Multiple Regression + Confounding (the FEV / airquality story) +95 XP
🧠 Simple Explanation

One predictor (SLR) is rarely the full story. A third variable can hide behind your predictor and lie about its effect.

Famous example: smokers in a kids' study seem to have BETTER lungs than non-smokers. Why? Because smokers are mostly TEENAGERS — older kids have bigger lungs. Age is the lurker.

Fix: include age in the model. Then smoke's coefficient flips to negative (the truth).

📐 Math Language
  • MLR model: \(\hat y = \hat\beta_0 + \hat\beta_1 x_1 + \hat\beta_2 x_2 + \cdots + \hat\beta_p x_p\)
  • Each \(\hat\beta_j\): estimated change in y per +1 in \(x_j\), holding all other predictors fixed.
  • Confounder: a variable Z that affects both X (the exposure) and Y (the outcome). Ignoring Z biases \(\hat\beta_x\).
  • R: lm(y ~ x1 + x2 + x3) — the + means "include both."
  • Conclusion language: "associated with… while adjusting for [Z]." Never "causes" without random assignment.
🔗 Connection
SimpleMath
"Hidden variable affecting both X and Y"Confounder Z
"Compare apples to apples"Adjust for Z by including in model
"Effect with Z held constant"\(\hat\beta_x\) in model with Z
"Bias in naive analysis"\(\hat\beta_x\) (no Z) ≠ \(\hat\beta_x\) (with Z)
"Hot days are sunny days"X (solar) and Z (temp) are positively correlated
"Pay for adjustment with bigger SE"Variance inflation when X and Z highly correlated
🍎 Intuitive Example — FEV vs Smoke + Age

n = 654 children, ages 3-19.

  • Naive: lm(fev ~ smoke) → smoke coef = +0.71 L (smokers seem BETTER!)
  • Adjusted: lm(fev ~ smoke + age) → smoke coef = −0.21 L (sign flips!)
  • Why? Smokers are systematically older. Age dominated the apparent effect.
  • Conclusion: "Smoking is associated with a 0.21-liter decrease in FEV, while adjusting for age (p = 0.010)."

  2. Throwing in every variable. Causes variance inflation and over-adjustment.
  3. Adjusting for a mediator. If Z is BETWEEN X and Y in the causal chain, adjusting for Z hides the X effect.
Level 58 — Partial F-Test (categorical predictors with k > 2 levels) +95 XP
🧠 Simple Explanation

You have a category with 3+ groups (e.g. species: setosa, versicolor, virginica). You want one answer: "Does species matter at all?"

R fits 2 dummy variables (one per non-reference group). The summary shows TWO p-values for species. You can't pick the smaller one — that's cheating.

The right answer: the partial F-test compares "model WITH species" vs "model WITHOUT species" and gives ONE p-value.

📐 Math Language
  • Dummy coding: a categorical with k levels becomes k − 1 binary indicators. Reference = baseline category.
  • Hypothesis: \(H_0: \beta_{\text{level 2}} = \beta_{\text{level 3}} = \cdots = \beta_{\text{level k}} = 0\) (ALL dummies zero).
  • F-statistic: \(F = \dfrac{(RSS_{\text{reduced}} - RSS_{\text{full}}) / p}{RSS_{\text{full}} / (n - k)}\) where \(p\) = # extra coefficients in full model, \(k\) = total coefs in full.
  • Null distribution: \(F \sim F_{p, n-k}\)
  • R: anova(reduced_model, full_model) — small first, full second.
  • R for p-value: pf(F, df1=p, df2=n-k, lower.tail=FALSE)
🔗 Connection
SimpleMath
"Does species matter at all?"\(H_0: \beta_{\text{vers}} = \beta_{\text{virg}} = 0\)
"Big improvement from adding species"Big drop in RSS from reduced to full
"Improvement vs noise floor"F = (RSS reduction per df) / (residual variance)
"Cheating: pick best p-value"Multiple-testing inflation of Type I error
"Three parallel lines"Same slope on covariate, different intercepts per category
🍎 Intuitive Example — Iris

n = 150 flowers (50 per species). Predict Petal.Length from Species + Petal.Width.

  • Full: lm(Petal.Length ~ Species + Petal.Width) → 4 coefficients (intercept + 2 species dummies + width slope).
  • Reduced: lm(Petal.Length ~ Petal.Width) → 2 coefficients.
  • p = 2 (the 2 species dummies). k = 4. n = 150.
  • anova(reduced, full) → F is huge, p < 2e-16. Reject \(H_0\). Species matters even after Petal.Width.
🎮 Interactive — Compute partial F by hand
full    <- lm(Petal.Length ~ Species + Petal.Width, data=iris)
reduced <- lm(Petal.Length ~ Petal.Width,           data=iris)

RSS_full    <- sum(residuals(full)^2)
RSS_reduced <- sum(residuals(reduced)^2)
n <- nrow(iris)
k <- length(coef(full))
p <- k - length(coef(reduced))

F_stat <- ((RSS_reduced - RSS_full) / p) / (RSS_full / (n - k))
pval   <- pf(F_stat, df1=p, df2=n-k, lower.tail=FALSE)

anova(reduced, full)   # confirms manual computation

Level 59 — LINE Diagnostics (when to TRUST your t-test on a slope) +95 XP
🧠 Simple Explanation

Your model gave you a slope and a p-value. Should you believe them?

The classical t-test for the slope is valid only if 4 conditions hold (LINE). If they break, your "p < 0.05" might be lying.

You check by looking at the residuals (the gaps between actual and predicted y). Patterns in residuals = broken conditions.

📐 Math Language — LINE
  • Linearity: \(E[y \mid x] = \beta_0 + \beta_1 x\) (the relationship really is a line).
  • Independence: \(\epsilon_i\) independent of \(\epsilon_j\) for all \(i \neq j\).
  • Normality: \(\epsilon_i \sim N(0, \sigma^2)\) (or n large for CLT).
  • Equal variance: \(\text{Var}(\epsilon_i) = \sigma^2\) constant across all x.
  • Diagnostics: residuals-vs-fitted (L, E), Q-Q plot (N), residuals-vs-order (I), Shapiro-Wilk test (formal N test).
🔗 Connection
What you seeDiagnosisLINE letter broken
Residuals form a curve, not a flat bandRelationship is nonlinearL
Cyclic / time pattern in residuals vs orderAdjacent observations correlatedI
Q-Q plot curves away from diagonalResiduals not normal (skewed or heavy tails)N
Residuals fan out (variance grows with x)HeteroskedasticityE
🍎 Intuitive Example — airquality

You fit lm(Ozone ~ Temp) on n = 111. Look at residuals:

  • Residuals vs fitted: clear curvature AND fan shape → L and E broken.
  • Q-Q plot: heavy tails → N broken (but n = 111 is large, so CLT might save β̂₁).
  • You CAN report the t-test p-value, but you MUST flag the diagnostic concerns and try a robust alternative (bootstrap CI or robust SE).
🎮 Interactive — Generate the 4 diagnostic plots
model <- lm(Ozone ~ Temp, data=aq)
res <- model$residuals
fit <- model$fitted.values

par(mfrow=c(2, 2))   # 2x2 grid

plot(res ~ fit, main="L & E"); abline(h=0, lty=2)
qqnorm(res, main="N");    qqline(res, col="red")
hist(res, breaks=20, main="N (histogram)")
plot(res ~ seq_along(res), main="I"); abline(h=0, lty=2)

par(mfrow=c(1, 1))

shapiro.test(res)            # formal normality test

  17. Shapiro reject N at α = 0.05, but at n = 5000 even tiny deviations reject. Use Q-Q plot — if it looks straight visually, you're fine; trust visual at large n.

However, residual diagnostics show curvature and heteroskedasticity, suggesting the linear model may be misspecified and standard errors may be biased. We confirm the result using a bootstrap CI / robust SE: [estimate range]."
⚠️ Common Mistakes
  1. Skipping diagnostics when reporting p-values. Diagnostics are part of the analysis, not optional.
  2. Trusting Shapiro-Wilk at large n. It rejects everything; use Q-Q plot visually.
  3. Assuming "no fan visible" = E satisfied. Subtle heteroskedasticity hides; always sanity-check with robust SE.
