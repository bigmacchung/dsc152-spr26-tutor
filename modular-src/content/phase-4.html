Level 23 - Practice Quiz Q7-8: Big Data and Bootstrap +60 XP

Q7: The Big Data Trap

Q7 Walkthrough

A/B test with n = 2 million, version B wins by 0.001%, p = 0.0001. Switch to B?

No! Effect is real (p tiny) but practically meaningless. Always check:

  1. p-value: very small = effect is real
  2. CI: very narrow = high precision
  3. Cohen's d: very small = trivial effect
  4. Does this matter in practice? No.

Q8: Bootstrap CI

Q8 Code
set.seed(123)
data <- c(23, 28, 19, 31, 25, 27, 22, 30, 26, 24)
mu0 <- 20
B <- 10000
n <- length(data)
boot_means <- rep(0, B)

for (i in 1:B) {
  boot_means[i] <- mean(sample(data, n, replace = TRUE))
}

ci <- quantile(boot_means, c(0.025, 0.975))
# Is mu0 = 20 inside CI? If outside: reject. If inside: fail to reject.

Bootstrap CI does NOT assume normality - works for skewed data too.

x     <- c(22, 19, 25, 27, 21, 18, 24)
mu0   <- 20
n     <- length(x)
xbar  <- mean(x)
s     <- sd(x)
t_stat <- (xbar - mu0) / (s / sqrt(n))
pval   <- 2 * (1 - pt(abs(t_stat), df = n - 1))
This is how t.test() computes its p-value under the hood.
pt(abs(t_stat), df = n-1) = left-tail area up to |t|. Two-sided p-value = 2 · (1 - that).

x     <- c(13.2, 25.0, 8.7, 31.4, 17.9, 22.3, 9.5)

signs <- x - mu0
n_pos <- sum(signs > 0)   # count of '+'

Prompt 2 — One-Sample Sign Test, Manually

Your data: x <- c(3.2, 2.8, 3.5, 3.1, 2.9, 3.0, 3.4, 3.6, 2.7, 3.3, 3.2, 3.8). Test H0: median = 3.0 vs. Ha: median > 3.0 at the α closest to 0.05. Report the rejection region, actual α, and p-value. Ignore ties with the null value (drop them).

Click for one correct solution 
x <- c(3.2, 2.8, 3.5, 3.1, 2.9, 3.0, 3.4, 3.6, 2.7, 3.3, 3.2, 3.8)
mu0 <- 3.0

# Drop ties, count values above mu0
x_no_ties <- x[x != mu0]
n <- length(x_no_ties)
x_above <- sum(x_no_ties > mu0)

# Find rejection region closest to alpha = 0.05
cutoffs <- 0:n
alphas <- sapply(cutoffs, function(k) {
  pbinom(k - 1, size = n, prob = 0.5, lower.tail = FALSE)
})
best_idx    <- which.min(abs(alphas - 0.05))
best_cutoff <- cutoffs[best_idx]
actual_alpha <- alphas[best_idx]

# p-value: P(X >= x_above | p = 0.5)
p_val <- pbinom(x_above - 1, size = n, prob = 0.5, lower.tail = FALSE)

cat("Rejection region: {", best_cutoff, ", ..., ", n, "}\n")
cat("Actual alpha:", actual_alpha, "\n")
cat("p-value:", p_val, "\n")

Key idea: Under H0 on the median, each observation is equally likely to be above or below μ₀, so the count above ~ Binomial(n, 0.5).

Prompt 3 — Two-Sided Sign Test p-value

Same data as Prompt 2, but now Ha: median ≠ 3.0. Compute the two-sided sign-test p-value.

Click for one correct solution 
x_no_ties <- x[x != 3.0]
n <- length(x_no_ties)
x_above <- sum(x_no_ties > 3.0)

p_low  <- pbinom(x_above, size = n, prob = 0.5)
p_high <- pbinom(x_above - 1, size = n, prob = 0.5,
                  lower.tail = FALSE)
p_val <- min(1, 2 * min(p_low, p_high))
p_val

Why min(1, 2 * min(...))? The discrete distribution under H0 is symmetric (Binomial(n, 0.5)), so the two-sided p is roughly 2× the smaller tail. The outer min(1, ...) guards against the tiny case where doubling pushes it above 1.

Prompt 5 — Power Simulation for a t-test

Under N(mean = 0.4, sd = 1) with n = 30, test H0: μ = 0 vs. Ha: μ ≠ 0 at α = 0.05. Simulate the power using 10,000 replicates.

Click for one correct solution

  samp <- rnorm(n, mean = 0.4, sd = 1)

Power pattern (memorize): generate data under Ha, run the test, count rejections, take the mean. The ONLY thing that distinguishes a power sim from a Type I sim is the data-generating mean (Ha vs. H0).

Prompt 6 — t-Test vs Sign Test Power Comparison

Under N(mean = 0.55, sd = 1) with n = 25, H0: μ = 0 (or median = 0) vs. Ha: not equal. Simulate 10,000 reps. Compare the power of the t-test vs. the two-sided sign test. Use α = 0.05 as the nominal cutoff for both.

Click for one correct solution 
# Two-sided sign test p-value helper
sign_test_pvalue <- function(x, mu0 = 0) {
  x <- x[x != mu0]
  n <- length(x)
  x_above <- sum(x > mu0)
  p_low  <- pbinom(x_above, size = n, prob = 0.5)
  p_high <- pbinom(x_above - 1, size = n, prob = 0.5,
                    lower.tail = FALSE)
  min(1, 2 * min(p_low, p_high))
}

set.seed(152)
B <- 10000
n <- 25
t_rej <- logical(B)
sign_rej <- logical(B)

for (b in 1:B) {
  samp <- rnorm(n, mean = 0.55, sd = 1)
  t_rej[b]    <- t.test(samp, mu = 0)$p.value < 0.05
  sign_rej[b] <- sign_test_pvalue(samp, mu0 = 0) < 0.05
}
mean(t_rej)
mean(sign_rej)

Expected result: t-test power ~ 0.90, sign test power ~ 0.70. At least a 20-point gap, as required. When the normality condition is met, the t-test is more powerful than the sign test.

Prompt 11 — Paired t-Test (Differences Trick)

Before and after a training program, you measured 8 players' free-throw percentages. Before: c(65, 70, 68, 72, 75, 60, 66, 71). After: c(70, 73, 72, 75, 78, 63, 70, 74). Did the program improve their shooting? Use a paired t-test at α = 0.05, both (a) using t.test(..., paired = TRUE) and (b) by computing differences manually.

Click for one correct solution 
before <- c(65, 70, 68, 72, 75, 60, 66, 71)
after  <- c(70, 73, 72, 75, 78, 63, 70, 74)

# (a) paired t-test shortcut

# (b) manually: one-sample t-test on the differences

t.test(diffs, mu = 0, alternative = "greater")

Key insight: A paired t-test IS a one-sample t-test on the differences. Both versions give the exact same p-value. On Quiz 1, if you see "paired," mentally convert to "one-sample test on after − before."
