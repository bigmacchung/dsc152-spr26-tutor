The Whole Course in One Picture

## Distributions
rbinom(n, size, prob)        # sample binomials
dbinom(x, size, prob)        # P(X=x) exactly
pbinom(q, size, prob)        # P(X ≤ q) cumulative
rnorm(n, mean, sd)
runif(n, min, max)
rgamma(n, shape, scale)
qt(p, df, ncp=0)              # t-quantile (e.g. critical value)
pt(q, df, ncp=0)              # P(T ≤ q); ncp for power
df(x, df1, df2)               # F-density (rare)

## Tests
t.test(x, mu=0)                          # 1-sample
t.test(y ~ group, data=df, var.equal=FALSE) # Welch 2-sample
power.t.test(n, delta, sd, sig.level=.05, type="one.sample")
shapiro.test(model$residuals)
anova(null_model, full_model)              # partial F

## Regression
model <- lm(y ~ x, data=df)             # SLR
model <- lm(y ~ x1 + x2 + x3, data=df)  # MLR
summary(model)                            # overview
summary(model)$coefficients              # coef matrix
confint(model, "x")                       # 95% CI
model$residuals; model$fitted.values

## Bootstrap (with replacement)
boot <- numeric(1000)
for (i in 1:1000) boot[i] <- mean(sample(x, length(x), replace=TRUE))
quantile(boot, c(.025, .975))

## Permutation (without replacement)
perm <- numeric(1000)
for (i in 1:1000) {
  shuffled <- df; shuffled$group <- sample(df$group)
  perm[i] <- diff_means(shuffled)
}
mean(abs(perm) >= abs(obs_stat))

## Sim power (one-sample example; adapt for slope or 2-sample)
sim_power <- function(n, mu_a, sigma, mu_0=0, reps=1000) {
  rej <- numeric(reps)
  for (i in 1:reps) {
    x <- rnorm(n, mu_a, sigma)
    rej[i] <- t.test(x, mu=mu_0)$p.value < 0.05
  }
  mean(rej)
}
⚠️ Top 8 Midterm Conceptual Traps
  1. "Statistically significant" ≠ "practically important." (Lec 5: bacon, poker, big data)
  2. "Failure to reject" ≠ "H₀ is true." Maybe you just had low power.
  3. Bootstrap (replace=TRUE) vs Permutation (replace=FALSE). Used for different questions.
  4. Adjustment ≠ causation. Only random assignment licenses causal language.
  5. Per-row t in MLR vs partial F. Different nulls. Different uses.
  6. "Validity" = correct Type I error rate. Conditions guarantee validity, not "the test is right."
  7. 1:N in R = both endpoints. Different from Python's range(1, N).
  8. Pretty p-values from broken diagnostics are fiction. Always check LINE before trusting your inference.
