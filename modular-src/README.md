# DSC152-companion — Modular Source

This folder is the **maintainable source of truth** for the DSC 152 study guide.
The file at `../DSC152-companion.html` is the **single-file build artifact** — generated by `build.sh` for portability.

## Build

```sh
cd modular-src
bash build.sh
# → produces ../DSC152-companion.html (single-file artifact)
```

The build script:
1. Reads `index.html` as the shell template
2. Inlines every `<link rel="stylesheet" href="styles/...">` as `<style>…</style>`
3. Inlines every `<script src="scripts/...">` as `<script>…</script>`
4. Inlines every content fragment (referenced via `<!-- @include content/phase-N.html -->`)
5. Writes the assembled HTML to `../DSC152-companion.html`

## Editing workflow

- **Add a new lecture's content?** Create `content/phase-N.html`, add an `@include` in `index.html`, add a phase-tab entry in `content/phase-tabs.html`, run `build.sh`.
- **Tweak a quiz handler?** Edit `scripts/quiz.js`, run `build.sh`.
- **Change a color?** Edit `styles/tokens.css`, run `build.sh`.

The single-file build is the deliverable; the modular source is for humans.
